# Yubi
![image](assets/yubi.png)

**Yubi** - это система быстрой навигации Windows с открытым исходным кодом.

Создавайте сценарии и оптимизируйте время работы за компьютером вместе с Yubi!

## Примеры использования
Взаимодействие пользователя с Yubi происходит с помощью сочетания клавиш Ctrl + Space. Yubi является командной строкой в центре экрана, которая открывается поверх других приложений. С её помощью вы можете выполнять как базовые действия - рассчитать математическое выражение, посмотреть прогноз погоды, установить напоминание, так и создавать свои сценарии самостоятельно, программируя автоматизацию работы с файлами на компьютере, обращение к сторонним API и администрирование системы.

Вместе с Yubi поставляется набор стандартных шаблонов сценариев, которые позволяют оптимизировать базовые рутинные задачи - открыть веб-сайт или сохранить текущее состояние рабочего стола Windows.

Кроме того, вы можете создать свой первый простой сценарий Yubi, назначив его на выполнение определённых действий - например, открыть приложение или назначить время будильника. Сценарий также может содержать дополнительные условия.

Гибкие сценарии позволяют задать команды для исполнения с определёнными условиями - "Открыть программу FL Studio версии 21", "Назначить одноразовый будильник на завтра" или "Поиск запроса {x} в Google".

## Конструктор сценариев
Также Yubi предлагает свой собственный конструктор сценариев: используя логические операции НЕ, И, ИЛИ, вы можете изменить готовые шаблоны под свои потребности или написать собственные. Конструктор сценариев Yubi предлагает визуальное построение последовательностей команд, размещая логические блоки и соединяя их.

Yubi основан на Python, что позволяет вам использовать весь каталог модулей Python при проектировании своих собственных сценариев.
